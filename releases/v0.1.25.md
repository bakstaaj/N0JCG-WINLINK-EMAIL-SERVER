# N0JCG Winlink Email Server v0.1.25

USB gadget boot and Windows RNDIS reliability release.

## Highlights

- Retry USB device-controller discovery during boot and reject the Orange Pi host-side controller.
- Fail the gadget service when no usable USB device controller is present so systemd can retry it.
- Match the Linux legacy RNDIS device-class descriptor used by the Windows-compatible reference gadget.
- Use stable RNDIS endpoint MAC addresses and a conservative transmit queue size for Windows DHCP and reconnect stability.
- Retry the gadget service after transient boot-time controller or ConfigFS failures.

## Validation

- Python unit tests pass.
- Bash syntax and repository diff checks pass.
- Release package contains the updated USB gadget service and script.

## Hardware boundary

USB gadget mode still requires the Orange Pi USB-C OTG/device port, a data-capable cable, and kernel support for the USB device controller and RNDIS function. Windows driver matching and the Pi-side DHCP/IP path remain separate commissioning checks.
