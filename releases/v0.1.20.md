# N0JCG Winlink Email Server v0.1.20

Operator connectivity and Orange Pi deployment reliability release.

## Highlights

- Fixed operator-console diagnostics so all status tiles load reliably.
- Existing Wi-Fi, hotspot, and operator account values are displayed and remain editable.
- Added visible password-field guidance and preserved show-password controls.
- Prevented unchanged Wi-Fi values from blocking hotspot-only changes.
- Hotspot SSID changes now persist, reload NetworkManager, and cycle an active access point.
- Added a Wi-Fi disable control that disconnects Wi-Fi and enables the configured hotspot.
- Added ConfigFS and libcomposite setup for USB gadget initialization on fresh installs.
- Added Orange Pi-compatible USB gadget startup handling and fallback SSID reconciliation.

## Validation

- Python unit tests pass: 54 tests.
- Python compilation, Bash syntax, and Git diff checks pass.

## Hardware boundary

USB gadget mode still requires an Orange Pi USB-C OTG/device port, a data-capable cable, and kernel support for the USB device controller.
