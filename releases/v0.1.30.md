# N0JCG Winlink Email Server v0.1.30

Unified Wi-Fi and hotspot mode release.

## Highlights

- Replace separate Wi-Fi disable and hotspot fallback controls with one
  `Use hotspot mode (disable Wi-Fi)` switch.
- Enable hotspot and automatic fallback together when hotspot mode is selected.
- Disable hotspot fallback and reconnect to the saved LAN Wi-Fi when hotspot
  mode is cleared.
- Keep USB gadget networking as an independent failsafe option.
- Preserve the saved SSID/password configuration and offline-safe RMS cache
  behavior from v0.1.29.
