# N0JCG Winlink Email Server v0.1.18

## Highlights

- Added the v0.1.18 release identifier to the operator console and webmail footers.
- Added direct links to the N0JCG website, LinkedIn, and X pages in both application footers.
- Preserved the on-demand GPS polling and RF-session GPS pause behavior from v0.1.17.
- Logout now clears the previous mailbox progress message before returning to the login form.
- The deployment script now verifies that the Pi actually went offline and returned with a new boot identity after the scheduled reboot.

## Validation

- Python unit tests pass: 53 tests.
- Python compilation, shell syntax, and repository diff checks pass.

## Hardware boundary

The WES remains a client-side appliance. RF operation still requires a commissioned radio, DigiRig, audio path, PTT path, and compatible Packet RMS gateway.
