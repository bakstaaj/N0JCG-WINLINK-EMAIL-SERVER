# N0JCG Winlink Email Server v0.1.7

Registration and trial-download control release.

## Highlights

- Standard N0JCG registration flow now requires both License S/N and registered email address.
- Uses product ID `winlink-email-appliance` and license prefix `N0JCG-WLA-`.
- Added shared N0JCG licensing client support with persistent device identity and signed license lease storage.
- Trial mode accepts one inbound message per Winlink login; registered installations have unlimited downloads.
- Trial Refresh ends the current mailbox session and requires a new Winlink login before another download.
- Registration controls use full-width, separate-row inputs in the operator console.
- Fixed systemd write permissions for persistent licensing state.
- Rebuilt and deployed the ARM64 client-side Packet RMS Pat build.

## Validation

- 42 Python unit tests pass.
- API syntax validation passes.
- Fresh ARM64 Pat client build completed through Docker.
- Raspberry Pi deployment completed successfully with the webmail service active.
- Release ZIP contents were inspected for the current registration and trial controls.

## Hardware boundary

This remains a client-side appliance, not an RMS gateway. Radio, DigiRig Mobile, packet modem, PTT, and RF operation require compatible hardware, operator commissioning, and local verification.
