# N0JCG Winlink Email Server v0.1.0

Initial packaged release of the N0JCG-branded Raspberry Pi client-side Winlink email appliance.

## Included

- Raspberry Pi 4 / 64-bit Debian deployment helper
- Guided MSYS2 Bash deployment with prompted Pi IP, SSH username, and password
- Password-protected Nginx operator console
- Winlink CMS authentication and isolated per-callsign mailbox access
- Branded webmail with Inbox, Sent, Drafts, Send queue, signatures, custom folders, drag-and-drop organization, logout, and attachment limits
- Operator diagnostics and service verification
- N0JCG-branded end-user guide in DOCX, PDF, and Markdown formats

## Hardware boundary

This is a client-side appliance, not an RMS gateway. Radio, DigiRig Mobile, packet modem, PTT, and RF operation require separate hardware connection and verification. Transmission remains disabled until explicitly configured and verified by the operator.

## Installation

From MSYS2 Bash:

```bash
git clone https://github.com/bakstaaj/N0JCG-WINLINK-EMAIL-SERVER.git
cd N0JCG-WINLINK-EMAIL-SERVER
./deploy/push_to_pi.sh
```

The installer prompts for the Raspberry Pi IP address, SSH username, SSH password, and initial operator username/password confirmation.
