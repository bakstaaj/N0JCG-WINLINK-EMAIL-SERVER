# N0JCG Winlink Email Server v0.1.5

Packet receive calibration and transfer reliability release.

## Highlights

- Starts automatic DigiRig receive calibration at `0/35` on every run and persists the selected gain for service restarts.
- Correlates S/N measurements with confirmed Dire Wolf packet decodes so noise alone cannot increase gain.
- Adds the persistent gain helper and audio tee used by the Dire Wolf service.
- Preserves granular mailbox progress and the one-user RF session guard while carrying the current operator UI updates.

## Validation

- Python compilation and unit tests passed before packaging.
- The deployed Dire Wolf, AGW bridge, and webmail services were verified active during the final RF test cycle.

## Hardware boundary

This remains a client-side appliance, not an RMS gateway. Radio, DigiRig Mobile, packet modem, PTT, and RF operation require compatible hardware, operator commissioning, and local verification.
