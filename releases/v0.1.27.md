# N0JCG Winlink Email Server v0.1.27

Installation content-cache refresh release.

## Highlights

- Refresh the Winlink RMS Packet gateway list during installation.
- Download and cache the current Winlink Standard Forms library during
  installation.
- Preserve existing caches and continue installation when either upstream
  source is temporarily unavailable.

## Cache locations

- RMS gateways: `/var/lib/n0jcg-winlink-webmail/rms-gateways.json`
- Standard Forms: `/var/lib/n0jcg-winlink-webmail/templates/standard/`
