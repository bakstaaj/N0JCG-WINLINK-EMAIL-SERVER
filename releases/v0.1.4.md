# N0JCG Winlink Email Server v0.1.4

Mailbox synchronization progress and release documentation update.

## Highlights

- Keeps the offered-message total stable for the entire RMS mailbox session.
- Reports RMS/PAT FBB transfer windows separately from the mailbox total.
- Prevents misleading displays such as `7 of 5` or `11 of 1`; an 11-message session now progresses from `0 of 11` to `11 of 11`.
- Caps progress at 100 percent and reports the remaining count from the immutable session total.
- Refreshes the branded webmail sign-in documentation image and user-guide text.

## Validation

- Python API compile check passed.
- Git whitespace validation passed.
- The deployed `n0jcg-webmail.service` is active on the WES.
- Existing 11-message transfer completed successfully before this release.

## Hardware boundary

This remains a client-side appliance, not an RMS gateway. Radio, DigiRig Mobile, packet modem, PTT, and RF operation require compatible hardware, operator commissioning, and local verification.
