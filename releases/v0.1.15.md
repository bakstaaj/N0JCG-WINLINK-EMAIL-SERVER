# N0JCG Winlink Email Server v0.1.15

## Highlights

- Fixed fresh-install DigiRig audio startup on Orange Pi and other Linux hosts
  where ALSA card names or indexes differ from the development system.
- Dire Wolf now resolves the live capture/playback card at service startup and
  uses a runtime configuration for the detected device.
- Optional mixer gain controls no longer prevent Dire Wolf from starting when
  a USB audio interface is temporarily unavailable or lacks that control.
- Packet radio profile generation no longer hardcodes `plughw:Device,0`.
- Added automated coverage for runtime ALSA resolution and non-fatal mixer setup.

## Validation

- Python unit tests pass: 52 tests.
- Python compilation, shell syntax, and repository diff checks pass.

## Fresh-install note

Run the installer from the extracted source tree. It installs missing Nginx and
Dire Wolf packages, detects the platform services, preserves operator-selected
radio settings, and prompts for the initial operator credentials.

## Hardware boundary

This remains a client-side appliance, not an RMS gateway. Radio, DigiRig Mobile,
packet modem, PTT, and RF operation require separate hardware connection and
verification.
