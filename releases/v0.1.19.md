# N0JCG Winlink Email Server v0.1.19

## Highlights

- Added authenticated Operator settings for Wi-Fi network access.
- Added runtime controls for automatic hotspot fallback and USB gadget networking.
- Added operator-console username and password changes from the protected UI.
- Added a restricted privileged helper so network and authentication changes are validated and applied safely.
- Preserved sensitive Wi-Fi, hotspot, and operator passwords; they are never returned to the browser.
- Added a warning that applying Wi-Fi settings may disconnect the current browser session.

## Validation

- Python unit tests pass: 54 tests.
- Python compilation, shell syntax, and repository diff checks pass.

## Hardware boundary

USB gadget networking remains hardware-dependent. The WES is still a client-side appliance and RF operation requires a commissioned radio, DigiRig, audio path, PTT path, and compatible Packet RMS gateway.
