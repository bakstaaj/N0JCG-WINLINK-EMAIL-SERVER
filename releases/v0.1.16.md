# N0JCG Winlink Email Server v0.1.16

## Highlights

- Fixed GPS installation when a u-blox USB serial identity contains wildcard
  characters or other nonstandard naming.
- Added a stable `/dev/n0jcg-gps` udev alias for the supported u-blox 7 USB GPS.
- gpsd now receives a resolved device path rather than a literal wildcard.
- Preserved fallback support for resolved `/dev/serial/by-id` and tty paths.

## Validation

- Python unit tests pass: 52 tests.
- GPS setup shell syntax and repository diff checks pass.

## Hardware boundary

The GPS must have a clear sky view for a usable fix. The gateway finder can use
the cached list and simulated coordinates when a live fix is unavailable.
