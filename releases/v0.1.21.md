# N0JCG Winlink Email Server v0.1.21

Orange Pi USB gadget compatibility release.

## Highlights

- Prefer the kernel-provided RNDIS USB network function for Windows hosts.
- Retain ECM as a fallback for kernels that provide it.
- Fail with a clear diagnostic when neither USB network function is available.

## Validation

- Python unit tests pass.
- Python compilation, Bash syntax, and Git diff checks pass.

## Hardware boundary

USB gadget mode still requires an Orange Pi USB-C OTG/device port, a data-capable cable, and kernel support for the USB device controller and RNDIS or ECM function.
