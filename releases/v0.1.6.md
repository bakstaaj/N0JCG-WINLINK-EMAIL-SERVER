# N0JCG Winlink Email Server v0.1.6

Mailbox text compatibility and field diagnostics release.

## Highlights

- Accepts UTF-8 mailbox responses and safely falls back to Windows-1252 for legacy forwarded-message punctuation.
- Prevents a single legacy byte such as `0x92` from making an otherwise valid Winlink message unavailable.
- Adds regression coverage for UTF-8 and legacy Windows-1252 mailbox responses.
- Updates the branded operator guide with mailbox text compatibility and slow Packet RMS transfer troubleshooting.
- Keeps the client-side appliance boundary, single-user RF session behavior, and external Packet RMS gateway workflow unchanged.

## Validation

- Python unit tests pass, including the new mailbox decoding tests.
- The updated branded DOCX and PDF guide were rebuilt from the current source.
- The release package includes the source tree, deployment helpers, UI, guide, screenshots, and ARM64 Pat client artifact.

## Hardware boundary

This remains a client-side appliance, not an RMS gateway. Radio, DigiRig Mobile, packet modem, PTT, and RF operation require compatible hardware, operator commissioning, and local verification.
