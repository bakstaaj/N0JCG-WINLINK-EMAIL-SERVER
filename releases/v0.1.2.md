# N0JCG Winlink Email Server v0.1.2

Cached RMS gateway selection, field location support, and faster send-queue state.

## Highlights

- Added an official Winlink RMS Packet gateway cache with refresh and offline use.
- Added GPS and simulated-coordinate support for finding the five closest gateways.
- Added a scrollable nearby-gateway panel; double-clicking a row populates the RMS target and frequency in the Packet station profile and focuses that panel.
- Made the selected RMS target dynamic for each Winlink client exchange after the operator saves a radio profile.
- Improved send-queue feedback: after Pat reports the final outgoing-transfer command, transmitted items are cleared promptly while the remainder of synchronization continues.
- Reduced webmail synchronization polling to make queue and navigation counters respond more quickly.
- Updated the N0JCG-branded end-user guide with gateway lookup, GPS/simulation, queue behavior, and current operating guidance.

## Validation

- Python unit tests pass, including RMS gateway normalization and nearest-gateway behavior.
- API syntax and repository whitespace checks pass.
- Raspberry Pi deployment completed successfully with the active webmail service verified.
- Official Pat v0.16.0 remains the transport client; no custom RMS protocol was introduced.

## Hardware boundary

This remains a client-side appliance, not an RMS gateway. Radio, DigiRig Mobile, packet modem, PTT, and RF operation require compatible hardware, operator commissioning, and local verification.
