# N0JCG Winlink Email Server v0.1.22

Windows USB RNDIS initialization release.

## Highlights

- Prefer the Orange Pi OTG xHCI device controller when multiple UDCs exist.
- Add Microsoft RNDIS OS descriptors for stable Windows driver initialization.
- Always configure and raise `usb0` even when NetworkManager initially reports no carrier.

## Validation

- Python unit tests pass.
- Python compilation, Bash syntax, and Git diff checks pass.

## Hardware boundary

USB gadget mode still requires an Orange Pi USB-C OTG/device port, a data-capable cable, and kernel support for the USB device controller and RNDIS or ECM function.
