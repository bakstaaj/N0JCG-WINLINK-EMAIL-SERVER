# N0JCG Winlink Email Server v0.1.14

## Highlights

- Added persistent DigiRig serial/PTT udev aliases for common CP210x, CH340,
  and FTDI adapters.
- Operator diagnostics now detect stable USB serial identities and compatible
  `/dev/ttyUSB*` fallbacks instead of depending only on fixed aliases.
- Added installer checks for a genuinely writable root filesystem and clearer
  read-only storage errors.
- Added retry/remount handling for transient filesystem state while applying a
  radio profile.
- Allowed the hardened webmail service to write only its required radio
  configuration directory under `/etc/n0jcg-winlink`.
- Improved installer compatibility with netplan/NetworkManager deployments and
  runtime DigiRig detection.

## Validation

- 43 Python unit tests passed.
- Bash syntax validation passed for the updated deployment scripts.
- Release archive excludes historical release bundles and runtime data.
