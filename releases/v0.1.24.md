# N0JCG Winlink Email Server v0.1.24

USB gadget lifecycle and networking reliability release.

## Highlights

- Use the Raspberry Pi RNDIS-compatible USB identity (`VID_2E8A`, `PID_0013`) so Windows can match its installed RNDIS INF.
- Separate USB ConfigFS gadget creation/removal from USB network activation.
- Add a clean systemd stop path and delayed network activation so `usb0` is created before NetworkManager configures it.
- Add udev settling before UDC binding and make the ConfigFS setup safe to restart.
- Install the required `dnsmasq` and `iptables` packages for NetworkManager shared IPv4 service during both normal deployment and connectivity setup.
- Preserve the existing USB gadget as a oneshot systemd service while retrying network activation when the Windows host connects.

## Validation

- Python unit tests pass.
- Python compilation, Bash syntax, and Git diff checks pass.
- Release package includes the USB gadget cleanup and network activation helpers.

## Hardware boundary

USB gadget mode still requires the Orange Pi USB-C OTG/device port, a data-capable cable, and kernel support for the USB device controller and RNDIS function. Windows driver matching and the Pi-side DHCP/IP path are separate commissioning checks.
