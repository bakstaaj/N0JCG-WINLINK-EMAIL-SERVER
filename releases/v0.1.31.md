# N0JCG Winlink Email Server v0.1.31

Reliable hotspot-to-LAN transition release.

## Highlights

- Stop the hotspot fallback watcher before switching the shared Wi-Fi adapter
  back to client/LAN mode.
- Tear down the hotspot profile before reconnecting the saved LAN profile.
- Prevent the hotspot service and NetworkManager from racing during mode
  changes.
