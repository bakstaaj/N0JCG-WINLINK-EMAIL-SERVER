# N0JCG Winlink Email Server v0.1.11

## Highlights

- Packet-radio configuration remains operator-controlled after installation.
- Creating or applying a valid packet profile now reloads systemd and restarts
  Dire Wolf after writing `direwolf.conf`.
- Installation reboot handling now waits for the Pi to return and verifies the
  Webmail service before reporting deployment success.

## Validation

- Installer and packet-profile Bash syntax validation passed.
- Release contents exclude generated runtime data and historical release
  archives.
