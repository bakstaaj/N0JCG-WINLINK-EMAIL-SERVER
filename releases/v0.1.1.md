# N0JCG Winlink Email Server v0.1.1

Webmail workflow, security, mailbox organization, and operator-control release.

## Highlights

- Webmail opens only after Winlink CMS secure-login acceptance; failed or timed-out RF authentication never creates a mailbox session.
- Automatic mailbox synchronization with an operator-configurable interval of 5–1440 minutes, defaulting to 30 minutes.
- Queueing a message immediately stages it into Pat’s official outbox and starts a Packet RMS synchronization.
- Send queue state and counters update automatically after successful transmission.
- Compose is the single new-message entry point; Standard Forms and Signature are available at the top of Compose.
- Draft-to-queue moves remove the draft from Drafts.
- Custom-folder moves remove messages from their source folder.
- Opening messages marks them read; Inbox, Sent, and custom folders support bulk mark-read and delete actions.
- Fixed message-detail and custom-folder authentication, URL decoding, read-state, and responsive preview behavior.
- Updated the N0JCG-branded end-user guide with installation, authentication, synchronization, templates, queue, folders, bulk actions, and troubleshooting guidance.

## Validation

- Python unit tests pass.
- API syntax validation passes.
- Nginx syntax validation passes on the Raspberry Pi deployment.
- Official Pat v0.16.0 remains the transport client.

## Hardware boundary

This remains a client-side appliance, not an RMS gateway. Radio, DigiRig Mobile, packet modem, PTT, and RF operation require separate hardware connection and verification.
