# N0JCG Winlink Email Server v0.1.23

USB gadget upgrade reliability release.

## Highlights

- Make RNDIS and ConfigFS setup safe to rerun on an existing gadget.
- Preserve existing ConfigFS functions and descriptor links during upgrades.
- Correctly recognize an already configured gadget before attempting changes.

## Validation

- Python unit tests pass.
- Python compilation, Bash syntax, and Git diff checks pass.

## Hardware boundary

USB gadget mode still requires an Orange Pi USB-C OTG/device port, a data-capable cable, and kernel support for the USB device controller and RNDIS or ECM function.
