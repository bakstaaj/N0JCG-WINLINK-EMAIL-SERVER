# N0JCG Winlink Email Server v0.1.28

Persistent network settings release.

## Highlights

- Persist the configured LAN and hotspot SSIDs independently of the currently
  active connection.
- Store the LAN and hotspot passwords in a root-readable `0600` secrets file.
- Populate the operator panel with saved values while keeping passwords masked
  until the operator enables the show-passwords control.
- Apply changed LAN credentials before leaving hotspot mode.
- Apply changed hotspot credentials for the next fallback activation.
