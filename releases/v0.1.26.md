# N0JCG Winlink Email Server v0.1.26

Static USB network release.

## Highlights

- Removed the USB-side DHCP process from the installer and boot service.
- Keep the Pi USB gadget at `192.168.60.1/24`.
- Require the Windows USB Ethernet adapter to use static `192.168.60.2/24`.
- Keep `dnsmasq` installed for the separate Wi-Fi fallback hotspot, which still
  provides DHCP on the hotspot interface.
- Start new installations hotspot-first with local client Wi-Fi disabled;
  enabling local Wi-Fi in the operator console stops the hotspot.

## Validation

- Python unit tests pass.
- Bash syntax and repository diff checks pass.
- The USB network service is a static `oneshot` service and does not launch
  `dnsmasq`.
