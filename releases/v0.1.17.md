# N0JCG Winlink Email Server v0.1.17

## Highlights

- GPS polling is now on demand rather than continuously active.
- Selecting “Use GPS” starts gpsd only long enough to acquire a fix, then
  stops it again.
- RF synchronization pauses GPS serial activity and restores it after the
  Packet RMS session completes, reducing USB contention with the DigiRig.
- Added a privileged guard helper with safe start, stop, pause, and resume
  operations for gpsd.

## Validation

- Python unit tests pass: 53 tests.
- Python compilation, shell syntax, and repository diff checks pass.

## Hardware boundary

On-demand polling reduces GPS bus activity but does not remove USB power. A
stable USB cable, hub, and power source are still required for reliable RF.
