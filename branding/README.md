# N0JCG Winlink Email Server branding

This client-side appliance follows the N0JCG Open Radio Platform Brand Guide v1.0 and Design System v1.0.

## Identity

- Master brand: `N0JCG` (the zero is the numeral 0).
- Visible product name: `N0JCG Winlink Email Server`.
- Descriptor: `Open Radio Platform`.
- Product role: client-side Winlink radio email and mailbox operations.
- Host role: `PI-WINLINK`.

The visible product name may be shortened to `Winlink Email Server` after first reference. Internal compatibility identifiers remain unchanged. This product is not an RMS gateway; it connects as a client to a Packet RMS gateway.

## Interface tokens

| Token | Value | Use |
| --- | --- | --- |
| Engineering Navy | `#0A1F44` | Header, high-emphasis text, dark field |
| Platform Blue | `#1565C0` | Primary actions and navigation |
| Signal Cyan | `#00B8D9` | Live packet/data activity and focus |
| Interface Mist | `#F4F7FA` | Working canvas |
| Operational Green | `#168A4A` | Verified healthy or completed state |
| Advisory Amber | `#B25E00` | Attention required |
| Fault Red | `#C62828` | Fault or blocked action |

Signal Cyan is not a generic success color. Every status uses a text label and does not rely on color alone. Hardware detection is not presented as verified RF or PTT operation.

## Type and voice

Use Inter for interface and body text, Orbitron sparingly for short display labels, and JetBrains Mono for callsigns, frequencies, timestamps, logs, and packet data. Use sentence case for headings and controls. The voice is precise, calm, direct, and constructive.
